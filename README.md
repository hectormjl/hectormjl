## Hector Jimenez — AI/ML Engineer

I build end-to-end machine learning and LLM systems — from data pipelines to
trained models to deployed APIs — with an emphasis on testing, CI, and
production-grade engineering practices, not just notebooks.

### Projects

**[document-qa-rag](https://github.com/hectormjl/document-qa-rag)**
A RAG system that answers questions over a document collection and grounds
every answer in the source text. Local embeddings (sentence-transformers) +
Chroma vector store + Claude for generation, with a hand-rolled evaluation
harness (retrieval hit rate, source accuracy, LLM-judged faithfulness).

**[weather-etl-pipeline](https://github.com/hectormjl/weather-etl-pipeline)**
An Airflow-orchestrated ETL pipeline that extracts weather data, transforms
it, and loads it into Postgres with idempotent upserts. Runs as a Docker
Compose stack with unit and integration tests.

**[heart-disease-predictor](https://github.com/hectormjl/heart-disease-predictor)**
An end-to-end ML project on the UCI Heart Disease dataset: EDA, feature
engineering, model comparison (Logistic Regression / Random Forest /
XGBoost), and a FastAPI service serving risk predictions — tested and
containerized.
